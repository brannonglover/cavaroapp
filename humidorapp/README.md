# Humidor — Marketing Site

A Next.js marketing site for the [Humidor](https://github.com/your-org/humidor) cigar companion app. Describes the app, its features, and the Free vs Premium tiers.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for production

```bash
npm run build
npm start
```

## Customize

- **App store links**: Update the App Store and Google Play URLs in `app/page.tsx` (search for `#download`) once the app is published.
- **Deploy**: Deploy to Vercel, Netlify, or any static host. The site is fully static.
